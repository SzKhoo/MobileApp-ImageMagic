# Superpowers skills (vendored)

These skills are vendored from the open-source **Superpowers** plugin by
Jesse Vincent (obra), so they travel with this repository and are available
in every Claude Code session (including ephemeral cloud sessions).

- Source: https://github.com/obra/superpowers
- Version: 5.1.0
- License: MIT (see `SUPERPOWERS-LICENSE`)

Claude Code auto-discovers these as project skills under `.claude/skills/`.

To update: re-copy the `skills/` directory from the upstream repo at the
desired tag. Alternatively, for an auto-updating install on your local
machine, use the plugin marketplace instead:

```
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace
```
